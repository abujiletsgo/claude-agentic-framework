SYSTEM OVERVIEW

시스템 구성

Claude Code 이벤트 발생 시 → caf-hooks(Rust)가 먼저 차단/기록 → global-hooks(Python)이 복잡한 로직 실행 → 데이터는 ~/.caf/에 저장 → Run Explorer가 시각화
caf-hooks Rust Binary
48개 훅 · 16개 이벤트 · 6–32x 빠름
Rust를 선택한 이유: PreToolUse는 모든 도구 호출 전에 실행. 지연 추가 금지.
global-hooks Python
자동화 · 가드레일 · 메모리 기록
Python으로 구현: 복잡한 로직(LLM 분류, DB 쓰기)은 성능보다 유연성 우선.
/orchestrate Skill

PO 에이전트가 비전 설정 → 컨설턴트가 스펙 작성 → 병렬 빌더가 구현.

MEMORY SYSTEM

메모리 시스템 — 4개의 레이어

Claude는 세션 간 기억이 없습니다. CAF는 세션 시작 시 구조화된 프로젝트 히스토리 ~2,800 토큰을 주입합니다. (Claude 모델 컨텍스트 창: 200K 토큰)
L3 시맨틱 Semantic ~/.claude/memory/ 글로벌 · 무기한 · 항상 주입 ~800 토큰
~/.claude/ 아래. 모든 프로젝트에서 공유. CLAUDE.md를 통해 항상 주입.
L2 에피소딕 Episodic .claude/MEMORY.md 프로젝트별 · 부분 주입 ~2,000 토큰
Git diff 기반 auto_memory_writer.py가 Stop 훅에서 MEMORY.md 자동 갱신.
L1 워킹 Working PROJECT_CONTEXT.md 세션 범위 · 자동 주입 ~1,000 토큰
현재 세션 TaskList, 수정 파일 경로, 인-세션 결정. 세션 종료 시 소멸.
L0 감각 Sensory 현재 턴 일시적 · 영속성 없음 무제한
현재 도구 출력. 각 응답 후 폐기. Claude의 단기 작업 버퍼.
신뢰 우선순위: CONFIRMED 사실 > CLAUDE.md 규칙 > 추론. CONFIRMED = validate_facts.py로 코드에서 직접 검증된 사실.
자동 주입 합계: ~2,800 토큰

HOOK SYSTEM

16개 이벤트 · 48개 훅

훅(Hook): Claude Code가 특정 이벤트 발생 시 자동으로 실행하는 스크립트. PreToolUse 훅은 도구 실행 전에 실행되어 차단 가능. exit code 1 반환 시 Claude가 해당 작업을 실행하지 않음. Compact: Claude Code가 컨텍스트 창 한계 도달 시 대화를 압축하는 내부 동작. PreCompact/PostCompact 훅으로 이 과정 전후에 실행.
